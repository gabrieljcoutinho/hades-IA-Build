# HADES

## Assistente Inteligente Interativo com IA, Voz e Aprendizagem Visual

---

# Sobre o Projeto

O **HADES** é um assistente inteligente interativo desenvolvido para oferecer uma experiência avançada de comunicação entre usuários e inteligência artificial.

Diferente de um chatbot tradicional, o HADES combina:

- Inteligência Artificial
- Interação por voz
- Interface futurista cyberpunk
- Resolução didática de problemas
- Geração de mapas mentais interativos
- Recursos visuais para aprendizagem

O principal objetivo do projeto é transformar informações complexas em conteúdos fáceis de compreender, utilizando explicações estruturadas, representações visuais e interações dinâmicas.

O sistema foi idealizado para atuar como um verdadeiro assistente digital pessoal, capaz de auxiliar em estudos, pesquisas, resolução de problemas matemáticos, organização do conhecimento e exploração de diversos assuntos através de uma interface moderna e intuitiva.

---

# Objetivos do Projeto

O HADES foi criado para resolver um problema comum presente em muitas inteligências artificiais atuais:

> Receber uma resposta correta não significa necessariamente compreender o assunto.

Por isso, o projeto busca unir três pilares fundamentais:

## 1. Conversação Inteligente

Permitir a comunicação natural entre usuário e IA através de texto e voz.

## 2. Explicação Estruturada

Demonstrar processos completos de raciocínio ao invés de apenas fornecer respostas prontas.

## 3. Aprendizagem Visual

Transformar conteúdos complexos em mapas mentais e representações visuais organizadas.

## Resolução Matemática Passo a Passo

Um dos recursos centrais do HADES é a resolução didática de problemas matemáticos.

Ao invés de mostrar apenas o resultado, o sistema demonstra todo o processo utilizado.

### Estrutura da Resolução

Cada resolução pode conter:

1. Enunciado do problema
2. Identificação dos dados
3. Fórmula utilizada
4. Substituição dos valores
5. Desenvolvimento dos cálculos
6. Explicação de cada etapa
7. Resultado final destacado

### Exemplo

#### Entrada

```text
Resolva:
x² - 5x + 6 = 0
```

#### Saída

##### Identificando os coeficientes

```text
a = 1
b = -5
c = 6
```

##### Aplicando Bhaskara

```text
Δ = b² - 4ac
Δ = (-5)² - 4(1)(6)
Δ = 25 - 24
Δ = 1
```

##### Calculando as raízes

```text
x = (-b ± √Δ) / 2a

x = (5 ± 1) / 2
```

```text
x1 = 3
x2 = 2
```

##### Resultado Final

```text
As raízes da equação são:
x1 = 3
x2 = 2
```

## Geração de Mapas Mentais

O HADES possui um sistema especializado para converter informações em mapas mentais organizados.

Ao solicitar um tema, a IA cria automaticamente:

- Tema central
- Conceitos principais
- Subtópicos
- Conexões entre informações
- Estruturas hierárquicas

#### Solicitação

```text
Explique a Revolução Industrial

├── Características

└── Impactos
    ├── Econômicos

    └── Tecnológicos
```

## Exploração Interativa dos Mapas Mentais

Os mapas mentais do HADES não são apenas elementos visuais estáticos.

Cada conceito pode ser explorado individualmente.

### Exemplo

Após gerar um mapa sobre Revolução Industrial, o usuário pode perguntar:

```text
Por que o avanço tecnológico foi importante?
```

O sistema irá:

- Identificar o conceito correspondente
- Explicar o tema detalhadamente
- Apresentar exemplos
- Relacionar a explicação com o restante do conteúdo

### Aprofundamento Progressivo

Caso necessário, o usuário pode solicitar:

```text
Explique com mais detalhes
```

O HADES então:

- Expande o tema
- Adiciona novas conexões
- Atualiza o mapa mental
- Insere novos conceitos relevantes

Criando uma experiência de aprendizagem gradual e personalizada.
